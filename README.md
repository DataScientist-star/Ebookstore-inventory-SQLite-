# Ebookstore Inventory CLI (SQLite)

A lightweight command-line inventory manager built with **Python** and **SQLite**.  
It demonstrates clean CRUD operations, relational schema design (foreign keys), input validation, and practical database constraints.

## Features
- Create, read, update, and delete **books**
- Linked **author ↔ book** relationship (foreign keys)
- Safe input handling (prevents invalid IDs/negative stock)
- View all books in a clean table format
- Automatic database initialization + seed data

## Tech Stack
- Python 3
- SQLite (`sqlite3`)
